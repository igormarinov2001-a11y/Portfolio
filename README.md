# The Northlane — лендинг

Статичный сайт на чистых HTML и CSS, без сборки и установки.

## Как открыть

Дважды кликните по `index.html` — страница откроется в браузере.

## Структура

```
index.html        — содержимое страницы (тексты, блоки)
css/styles.css    — внешний вид (цвета, шрифты, размеры, отступы)
fonts/            — файлы шрифтов
images/           — картинки
```

Цвета и шрифты вынесены в переменные в начале `css/styles.css` (раздел 2) —
меняются в одном месте.

## Что временное

- `fonts/` — вместо Nyght Serif пока Playfair Display (инструкция в `css/styles.css`, раздел 1)
- `images/hero-1.png` — вырезан из скриншота макета, нужен оригинал; остальные кадры слайдшоу `hero-2…7.png` пока 1x (396×232), для чёткости на ретине нужны 2x (792×464)
- `images/work-1…4.webp` — вырезаны из скриншота секции Selected Works (1x), нужны оригиналы в 2x
- мобильная версия: готовы шапка с бургером и меню, хиро, градиент (форма и «выглядывание»), About, лоадер (макет 393px); Selected Works (картинки карточек на телефоне временно вырезаны из макета 1x, нужны оригиналы 3x: 1113×774); мобильный градиент — временно обрезка десктопного, нужен вертикальный файл
