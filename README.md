# The Northlane — лендинг

Статичный сайт на чистых HTML и CSS, без сборки и установки.

## Как открыть

Дважды кликните по `index.html` — страница откроется в браузере.

## Структура

```
index.html        — содержимое страницы (тексты, блоки)
css/styles.css    — внешний вид (цвета, шрифты, размеры, отступы)
fonts/            — файлы шрифтов
images/           — картинки
```

Цвета и шрифты вынесены в переменные в начале `css/styles.css` (раздел 2) —
меняются в одном месте.

## Что временное

- `fonts/` — вместо Nyght Serif пока Libre Caslon Text, бесплатный, лицензия OFL (инструкция в `css/styles.css`, раздел 1)
- `images/hero-1.webp` — вырезан из скриншота макета, нужен оригинал; остальные кадры слайдшоу `hero-2…7.webp` пока 1x (396×232), для чёткости на ретине нужны 2x (792×464)
- `images/work-1…4.webp` — вырезаны из скриншота секции Selected Works (1x), нужны оригиналы в 2x
- мобильная версия: готовы шапка с бургером и меню, хиро, градиент (форма и «выглядывание»), About, лоадер (макет 393px); Selected Works (картинки карточек 1862×1288 для десктопа и телефона); мобильный градиент — временно обрезка десктопного, нужен вертикальный файл

## Services

Белая секция после Works: слева картинка + подпись, справа список из 6 услуг (hover/tap/focus переключает). Картинка и текст есть только у «Web Design» (из макета); у остальных пяти — временные картинки из Works и придуманные подписи. Мобильная версия — черновик (макета нет).

## Works

Тёмная секция: сетка 2 / 1 на всю ширину / 2, зазор 6px. Картинки работ (`work-1…5.webp`) пришли из макета вместе с запечёнными подписями: подписи убраны автоматически (inpainting), исходники без подписей лучше. Подписи (название слева, теги справа) — HTML поверх картинки: в покое на середине карточки, при скролле «прилипают» к центру экрана и уезжают вниз до 20px от края карточки (`position: sticky`); цвет (белый или почти чёрный) js выбирает по яркости картинки под текстом, чтобы был контраст. Кнопки «View all works» нет. Синяя бегущая строка при ховере убрана, остался зум картинки.
